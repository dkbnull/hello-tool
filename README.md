## 项目简介

HelloTool 是一个基于 Vue 3 和 Vite 构建的多功能开发工具箱，集成了多种常用开发工具，旨在提高开发效率。项目采用现代化的前端技术栈，提供直观易用的界面和丰富的功能模块。

## 功能特性

### 🛠️ 核心工具模块

- **时间戳转换** 
    - UNIX时间戳与日期格式互转
    - 支持秒和毫秒单位
    - 实时显示当前时间信息

- **JWT解密** 
    - JWT令牌解析和验证
    - Header和Payload内容展示
    - 过期时间检测和状态提示

- **JSON全能转换**
  - 格式化、压缩、验证JSON
  - JSON转XML/CSV/YAML
  - 一键复制功能
  - 实时预览转换结果

- **JSON XML互转** 
    - JSON与XML格式相互转换
    - 支持格式化输出
    - 错误提示和处理

- **JSON引号转换** 
    - 单引号转双引号（标准JSON）
    - 实时预览转换结果
    - 一键复制功能

- **JSON大小写转换** 
    - JSON字段大小写转换
    - 支持多种命名风格
    - 一键复制功能

- **命名格式转换** 
    - 驼峰、下划线互转
    - 支持多种命名风格
    - 一键复制功能

- **RSA密钥生成** 
    - 支持2048位密钥生成
    - 公钥私钥对生成和导出
    - 一键复制功能

- **BMI计算器** 
    - 计算身体质量指数
    - 显示BMI分类（偏瘦、正常、偏胖、肥胖）
    - 可视化BMI刻度条
    - 提供BMI计算公式

### 🎨 界面特色

- 响应式设计，支持多端访问
- 左侧导航栏，快速跳转到不同工具类别
- 左右分栏布局，信息展示清晰
- 现代化UI组件，用户体验友好
- 代码高亮显示，便于阅读
- 导航栏粘性定位，滚动时保持可见
- 悬停效果和动画，增强交互体验
